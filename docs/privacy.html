Privacy Policy

How Site Label handles your data - the short version is that it does not collect any.

Last updated: 17 August 2026

Site Label is a browser extension that draws a colour-coded label over websites you choose, so you can tell one environment from another.

The short version

Site Label collects nothing, sends nothing and stores nothing outside your own browser. It has no servers, no analytics and makes no network requests of any kind.

What is stored

Site Label stores the following on your own computer, using the browser's extension storage:

  • the address patterns you have chosen to label;
  • the label text, colours, position and display options you set;
  • the groups you create and which sites belong to them;
  • your extension settings.

That is all. This data never leaves your device unless you deliberately use the Export feature, which writes a file to a location you choose, and which you then share yourself.

What is not collected

Site Label does not collect, transmit, store or have access to:

  • your browsing history;
  • the content of any page you visit — text, form fields, credentials, documents or data;
  • cookies, local storage or session tokens belonging to any website;
  • your identity, IP address, location or any device identifier;
  • anything at all sent to the developer or to a third party.

There is no telemetry, no crash reporting, no advertising and no tracking. Nothing is sold or shared, because nothing is collected.

Website access

Site Label ships with no permission to access any website. When you add a label to a site, the browser asks whether to grant access to that specific site, and shows you the addresses involved. The extension uses that access for exactly one thing: injecting a script that draws the label overlay on the page.

That script does not read the page. It creates one element in a closed shadow root, draws the label, and keeps it in place while you navigate. It reads the page's address in order to decide whether a label applies, and the page's host name only if you have switched on the option to show it inside the label.

You can withdraw access at any time — per site or all at once — from the extension's Settings tab, or from edge://extensions. Deleting a label also releases the access it needed, provided no other label still requires it.

Import and export

Exported files contain only your label rules, groups and styling. They never contain browsing history or any page data. Imported files are treated as untrusted input: every value is re-validated before use, and importing a file does not grant access to any site — you are asked separately, and can decline.

Children

Site Label is a developer and consultant tool. It is not directed at children and collects no personal information from anyone.

Changes

If this policy ever changes, the revised version will be published with the extension and the date above updated.

Contact

Questions about this policy or the extension can be sent to the address listed on the extension's store listing.
