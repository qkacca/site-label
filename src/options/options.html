Site Label

Colour-coded labels so you always know which environment you are in.

Welcome. Open any site, click the Site Label icon, and add a label.

Site Label starts with access to no websites at all. It asks for one site at a time, as you add it, and tells you exactly what is being granted first. When Edge asks, it will say “Read and change your data on…” — that is the only wording Edge has for site access, and it describes what the permission could allow rather than what this extension does. All Site Label does with it is draw your label. It has no networking code, so nothing it sees can go anywhere. See Settings for the full list of permissions and what each is for.

What Site Label can access

Every permission this extension holds, and what each one is for. Four of them are fixed and none of those can see a website. The fifth is site access, which is asked for one site at a time as you add it.

Site Label contains no networking code of any kind — no requests, no analytics, no tracking, no remote scripts — so nothing it sees can be sent anywhere. Your labels leave this browser only if you export them to a file yourself.

Site access

These are the sites Site Label can currently see. Removing access here leaves the label rule in place but stops it being drawn until you grant access again. Deleting a label releases its access automatically.

Reset

Deletes every site, group and setting, and hands back all site access.

Keyboard

Alt+Shift+L hides or shows the label on the current tab. Alt+Shift+S opens the Site Label popup. Change these at edge://extensions/shortcuts.
